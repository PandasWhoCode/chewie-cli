# Chewie CLI

The Chewie CLI Tool is being developed as an extension of the Chewie GitHub application for end users to include with their chewie config. It is developed to provide additional helper functions that can be used by GitHub workflows to interface with Chewie.

The primary goal of the Chewie CLI tool is to provide workflows with interoperable methods to query the chewie API as part of a workflow step in GitHub actions.
